# TokenOut 1.2.0

A calmer, faster overview that keeps the limits you need visible without turning every menu-bar check into an analytics session.

## New

- **Both planning horizons at a glance**: compact provider cards show the active 5-hour limit and the tightest weekly limit together.
- **Today summary**: each provider groups today's token total and API-equivalent value into one concise row.
- **Progressive detail**: expand Claude Code or Codex independently to restore every limit, pace projection, breakdown, range control, metric tile, and daily chart.

## Improved

- Normal usage now uses neutral, adaptive bars. Orange and red are reserved for conditions that need attention.
- Larger sentence-case labels, stronger numeric hierarchy, calmer chart colors, and clearer grouped surfaces improve readability in light and dark appearances.
- Reserve and on-pace states no longer compete with warning colors.
- Expansion uses a critically damped, interruptible spring and switches to a gentle transition when Reduce Motion is enabled.
