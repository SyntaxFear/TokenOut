# BurnBar 1.0.0

The first public release of BurnBar.

- Track Claude Code, Codex, and Antigravity from the macOS menu bar.
- Review limit windows, token totals, cost estimates, daily history, and provider breakdowns.
- Choose used or remaining percentages throughout the app.
- Configure display sections, refresh cadence, alerts, launch at login, and automatic updates.
- Refresh Claude Code with its current first-party OAuth scope and preserve rotated credentials safely.
- Keep all BurnBar usage history and preferences local to the Mac.
